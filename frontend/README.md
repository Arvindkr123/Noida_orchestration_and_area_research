# Noida Area Research - Simple Frontend

A basic React + Vite interface for the FastAPI research backend.

## Run

1. Extract this folder.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:5173.

The backend should be running at http://localhost:8000.

If needed, create `.env` from `.env.example` and set `VITE_API_BASE_URL`.

## Backend CORS

Allow `http://localhost:5173` in FastAPI CORS settings.
